# Network Topology Analyzer

## Description

A CLI tool for scanning and visualizing network topology using DNS records and IP geolocation data.

## Installation

```bash
pip install .
```

## Usage

```bash
network-topology-analyzer scan <domain>
network-topology-analyzer visualize <graph-file>
```

## Requirements

- Python 3.8+
- `geoip2`
- `dnspython`
- `networkx`
- `matplotlib`
